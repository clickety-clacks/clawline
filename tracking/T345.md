## Goal

Add a Spatial-only soft viewport fade mask for Clawline chat content so scrolling bubbles fade out as they approach the Spatial window boundaries instead of hard-clipping at the edge.

## Product Truth

This is specific to the native Spatial/visionOS Clawline window. The effect should make chat bubbles feel like they pass naturally under the Spatial window chrome. It must not change iOS, iPadOS, Catalyst, or web chat rendering unless a shared implementation seam is required with no visible behavior change outside Spatial.

Related prior art: T258 tracks a general chat top soft scroll edge fade, but T345 is a separate Spatial-only four-edge viewport mask: top, bottom, left, and right.

## Acceptance Criteria

- **T345-01:** In Clawline Spatial, chat transcript/bubble content fades out near the top edge before it hard-clips at the Spatial window boundary.
- **T345-02:** In Clawline Spatial, chat transcript/bubble content fades out near the bottom edge before it hard-clips at the Spatial window boundary.
- **T345-03:** In Clawline Spatial, chat transcript/bubble content fades out near the left edge before it hard-clips at the Spatial window boundary.
- **T345-04:** In Clawline Spatial, chat transcript/bubble content fades out near the right edge before it hard-clips at the Spatial window boundary.
- **T345-05:** The fade reads as a soft viewport mask, not as a dark overlay, blur blob, card, or decorative gradient sitting above the chat.
- **T345-06:** The mask affects visual clipping only; it must not create dead hit-test zones or break scrolling, selecting, links, notification overlays, @mention picker layering, or bottom corner indicators.
- **T345-07:** The implementation is Spatial-only, or any shared code is guarded/proven so iOS/iPadOS/Catalyst/web behavior does not visibly change.
- **T345-08:** Verification includes a Spatial build gate and either focused automated proof where practical or a clear manual Cyberbrain verification target.
- **T345-09:** No deploy, merge, branch cleanup, or agent spindown occurs without explicit Flynn authorization.
- **T345-10:** The left and right Spatial fade zones keep the current fade strength but reduce the fade width by roughly half from the previously accepted deployed behavior. They must not get wider or read more visually dominant.
- **T345-11:** In Clawline Spatial only, the bottom fade reaches higher than current main; Flynn's latest target is about one-third taller than the current Cyberbrain behavior, not doubled.
- **T345-12:** In Clawline Spatial, the left and right fade widths should be approximately the gutter width between the Spatial window edge and the chat bubbles, so the fade reads as the bubble-to-window boundary treatment rather than a broad overlay over message content.
